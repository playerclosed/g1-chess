# G1 Chess - Even Realities G1

Schachspiel fuer die G1 Smart Glasses via MentraOS.

## Sprachbefehle

- `e2 e4` oder `e2 nach e4` — Zug von e2 nach e4
- `Springer f3` — Springer nach f3
- `Dame d1` — Dame nach d1
- `Rochade` — Kurze Rochade
- `neu` — Neues Spiel
- `aufgeben` — Aufgabe

## Umgebungsvariablen (Railway)

| Variable | Wert |
|----------|------|
| `MENTRA_API_KEY` | Mentra CLI Key |
| `PACKAGE_NAME` | `com.player.codewords-chess` |

## Deployment

Railway erkennt automatisch Bun/Node.js. Verbinde dieses Repo und setze die Umgebungsvariablen.
